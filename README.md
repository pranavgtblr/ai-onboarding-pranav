# ai-onboarding-pranav

## Rules

- **One branch and one PR per task.** Branch name is the task ID: `task/2.6-tool-loop`.
- **Every task ID becomes a GitHub issue.** Close it when the PR merges.
- **Copy the checklists into [PROGRESS.md](PROGRESS.md) and tick them as you go.**
- **A task is done when the code runs and has a README explaining how to run it.** Not when the reading is done.
